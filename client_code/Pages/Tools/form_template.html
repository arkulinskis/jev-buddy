Which number do I paste?

The probability of the answer Jev picked: pmax for a choice, p or 1 − p for a noul (whichever side it picked). Jev's confidence field is rescaled ((pmax − 1/n) / (1 − 1/n), see the Confidence calculator), so it reads lower than the hit rate even when the probabilities are calibrated. It still works for picking thresholds; just don't read it as a hit rate. The guide's tune.py writes this file for you.
