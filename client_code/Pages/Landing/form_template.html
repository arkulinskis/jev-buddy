Your LLM is writing essays to answer yes-or-no questions

Most "AI decisions" in production are classification in disguise: route this, flag that, rate the other. Generating text for them is slow, costly and fragile.

The LLM way

  • Pays for output tokens nobody reads
  • Labels drift, JSON breaks, retries pile up
  • "How sure are you?" gets a made-up number

The Jev way

  • Input tokens only, about a fifth of a second
  • Always one of your options, never malformed
  • Probabilities you can put thresholds on

Questions

What exactly is Jev?

A "System One" decision model from TypeSafe AI, launched in September 2026. You give it state and typed questions; it returns choices, yes/no probabilities and scores. It never generates text.

Is Jev Buddy made by TypeSafe?

No. Jev Buddy is an independent guide. We link every source we used, and the official docs always win.

Do I need an account here?

No. The guide, use cases, tools and playground simulator are free and open. An account lets you save and share recipes, and run real Jev calls in the playground when live runs are switched on.

Is the playground real?

It shows a clearly labelled simulation (keyword overlap) unless live runs are on, in which case signed-in members get real Jev answers through OpenRouter. The Code tab gives you a script to run with your own key either way.

Can I use it without sending data to TypeSafe?

Not with Jev itself: it is closed and only runs on TypeSafe's servers. Open-source models such as Laya, Kev and jevos run on your own computer or server and answer the same kinds of questions. Our Open source page shows how to install and call each one, and the playground's Code tab has a Self-hosted version of every request.

Can Jev extract names, amounts or dates?

Not directly: it doesn't write text. It answers questions with answer spaces you define (categories, yes/no, levels). Pair it with a parser or an LLM for free values; the guide shows how.

How accurate is it?

Very good on simple, focused questions; less so on complex or ambiguous ones, which then get lower confidence. Measure it on a labelled sample of your own data before automating anything that matters.
