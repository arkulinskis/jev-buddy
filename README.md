# Jev Buddy

Jev Buddy is a free, multipage developer guide to **Jev**, TypeSafe AI's "System One" decision model: you send it
state (text or JSON) and typed questions (choice, noul, score), and it returns typed answers with calibrated probabilities
instead of text. The site explains everything a developer needs (with code in Python, TypeScript, curl and TypeSafe's SDK),
shows twelve business use cases with routing code and costs, and has a playground, saved "recipes" and calculators.
It is an independent guide, not affiliated with TypeSafe or OpenRouter. Built on [Anvil](https://anvil.works).

- **App repo:** github.com/arkulinskis/jev-buddy (branch `master`). Anvil pulls `master`.
- **Live:** https://jev-buddy.anvil.app

## What it does

**For everyone (no account needed):**
- **Landing** (`#landing`): animated "decision terminal" hero, key numbers ($0.042/M input tokens, $0 output, ~0.21 s),
  LLM vs Jev comparison, the three primitives, use cases, audiences, FAQ.
- **Guide** (`#learn`, `#learn/<chapter>`): 15 chapters in 4 groups (Start here, The three primitives, Build, Reference):
  what Jev is, quickstart, request anatomy + `ask()` helper, choice, noul, score, support inbox, extracting information,
  confidence and thresholds, production, providers and SDKs, writing good questions, patterns, gotchas, sources.
  Sticky chapter list, read ticks + progress (browser), code tabs that remember your language, copy buttons.
- **Use cases** (`#examples`, `#examples/<slug>`): 12 business examples (support inbox, lead scoring, injection guard,
  agent tool gate, moderation, expenses, RAG filter, claims, reviews, churn, reply sorting, contract clauses) with the
  problem, the state, the request in 5 languages, illustrative answers, routing code, tips and monthly cost.
- **Playground** (`#playground`, `#playground/recipe/<id>`): visual builder for state + questions, templates from the use
  cases, live validation, Answers / Request / Code tabs, Ctrl+Enter. Answers come from a clearly labelled in-browser
  **simulator** (keyword overlap, not Jev) unless an admin has switched **live runs** on; then signed-in members get real
  Jev answers through OpenRouter (server-side key, per-person and daily limits).
- **Recipes** (`#recipes`, `#recipes/<id>`): community gallery of shared requests (search, category, Top/New, likes,
  forks), detail page with code; 12 demo recipes from fictional people.
- **Tools** (`#tools/cost`, `#tools/confidence`, `#tools/thresholds`): cost calculator vs an editable LLM baseline
  (prefilled from a use case via `#tools/cost/<volume>/<tokens>/<questions>`), confidence calculator with TypeSafe's
  formulas, threshold simulator on synthetic data.
- Feedback form, Privacy & Terms, light/dark theme, phone tab bar with a "More" sheet.

**For members:** save recipes from the playground (private or shared), edit their own, fork others', like, delete
(`#recipes/mine`); live playground runs when switched on.

**For admins** (`#admin`; arkulinskis@gmail.com becomes an admin on first sign-in):
- **Overview:** members, feedback, recipes, live runs today.
- **Feedback inbox:** New / Read / Done, private notes.
- **Users:** search, make admin, disable an account.
- **Jev API:** paste an OpenRouter key (stored server-side, never sent to browsers), model, daily cap, per-person hourly
  limit, live on/off, test call, usage (runs, errors, cost, latency). Off by default.
- **Recipes:** hide or show shared recipes (private ones are never listed).
- **Demo data:** demo people and recipes; remove or reload.

## Setting it up in Anvil (once)

1. In the Anvil editor: **Create app → Clone from GitHub**, and paste `https://github.com/arkulinskis/jev-buddy`.
2. **Users** service: email + password and "Continue with Google", sign-up allowed (already set in `anvil.yaml`; check it).
3. Open the app in the editor. If it shows a **Schema Mismatch** alert, choose **"The schema of the source code is correct"** so Anvil creates the tables.
4. **Run** it and sign up with **arkulinskis@gmail.com** straight away (that account becomes the admin).
5. **Publish** (Publish → public URL, or your own domain).
6. Optional: **Admin → Jev API**, paste an OpenRouter key and switch live runs on, so members get real Jev answers in the playground.

## Working on it

See `.claude/skills/jevbuddy/SKILL.md`. In short:

```
python -I tools/check.py --ui                    # syntax, server tests, headless UI tests → ALL CHECKS PASSED
python -I tools/preview/devserver.py 8765        # the app on in-memory data: http://localhost:8765/  (?as=ana#learn, ?as=admin#admin)
python tools/deploy.py                           # dry run (needs PyYAML, so no -I)
python tools/deploy.py --push "Message"          # deploy: commit + push to GitHub, Anvil pulls it
```
